# Blender Pilot v0.1.0 — Initial Preview

The first public preview of a self-hosted Blender workspace powered by **Codex and MCP**. Create through conversation, reuse assets, and keep each project's scene and history together.

## What's included

- **Conversation workspace:** streamed messages, reference images and Markdown documents, visible tool activity, cancellation, history recovery and automatic scene captures.
- **Reusable assets:** shared character, prop, scene and material categories; Blender/model imports and ZIP packages with local dependencies; cross-project references.
- **Multiple projects:** independent scenes and conversations, project rename, durable create-request receipts and guarded scene restoration.
- **Templates and skills:** configurable creation recipes, skill uploads and a public GitHub/npx installation flow.
- **Native or Docker deployment:** reuse an installed Blender executable, or provision a Linux x86-64 container runtime; PostgreSQL metadata and local files.
- **Polished UI:** neutral light/dark themes, resizable assistant, keyboard controls, responsive typography and system-health views.
- **Open-source documentation:** English/Chinese READMEs, 16 current UI screenshots, MIT license and third-party notices.

## Get started

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/shiluyuan/blender-pilot.git
cd blender-pilot
./docker-up.sh
```

Docker mode targets Linux x86-64 and includes its own Blender runtime. A host Blender installation is not required. Open `http://SERVER_IP:8090`, use the access password printed by the launcher, then set your **Base URL, API Key and model** in Settings. The provider must support Responses streaming, image inputs and tool calls.

To reuse Blender already installed on the same machine, first prepare Node.js 22.12+/24 LTS, Python 3.12+, PostgreSQL and Blender:

```bash
export DATABASE_URL='postgresql://pilot:YOUR_PASSWORD@127.0.0.1:5432/pilot'
./docker-up.sh --native --setup
```

Headless Linux additionally needs Xvfb, Openbox and x11vnc for the embedded desktop. Native-window mode uses local Blender windows and browser screenshot previews. See the [native guide](https://github.com/shiluyuan/blender-pilot/blob/v0.1.0/docs/native-deployment.md) and [Docker guide](https://github.com/shiluyuan/blender-pilot/blob/v0.1.0/docs/deployment.md).

## Validation and preview limits

Recorded source validation includes **126 Node tests and 16 Python tests**, typecheck and production build. Browser regressions cover **19 chat, 16 interface/status, 7 project and 18 skills/workflow checks**, with zero uncaught application errors in those runs.

The cloud SQL checks explicitly use PostgreSQL WASM over TCP with the real pg driver. Browser runner/model responses and public npx downloads are fixtures. These results are not a new live-model, real-Blender, native PostgreSQL or Docker target-host certification. Physical macOS and Windows/WSL acceptance remains pending. Claude integration is planned; this release supports Codex. This is a **pre-release**, and APIs/deployment details may evolve.

Full evidence and platform boundaries: [validation](https://github.com/shiluyuan/blender-pilot/blob/v0.1.0/docs/release-0.1.0.md), [sidebar review](https://github.com/shiluyuan/blender-pilot/blob/v0.1.0/docs/sidebar-quality-review.md), [screenshot provenance](https://github.com/shiluyuan/blender-pilot/blob/v0.1.0/docs/screenshots/latest/README.md).
