# 技能管理

技能是可复用的制作流程，例如角色比例检查、场景灯光整理或素材归档。Blender Pilot 将选中的技能作为 Codex 原生的技能输入交给当前任务，并通过 Blender MCP 执行场景操作。技能中心与素材库分开：技能描述“怎么做”，素材保存“可以复用什么”。

## 上传技能

在左侧打开“技能中心”，选择上传 SKILL.md 或 ZIP 包。单个文件应包含 YAML 头部和正文：

```markdown
---
name: blender-scene-review
description: 检查 Blender 场景比例、材质和构图，输出可复核的证据。
---

先读取场景对象和尺寸。
获取多个角度的截图，再读取结构报告，分别检查遮挡、悬空、灯光和构图。
修复问题后重新截图。明确区分已验证项目、待人工判断项目和剩余问题。
```

名称为 1–64 位小写字母、数字与连字符，描述最长 2000 字符。正文必须是 UTF-8 文本，单个 SKILL.md 最多 64 KiB。

需要参考文档、脚本源码或图片时，将它们与 SKILL.md 放在同一目录后打包。ZIP 可以包含多个独立技能目录；不接受嵌套的技能根目录。技能详情会显示正文及文件清单。上传上限为 10 MiB，解压总量 50 MiB，最多 500 个文件及目录。加密 ZIP、ZIP64、符号链接、特殊文件和越界路径不受支持。

## 通过 npx 安装

输入公开 GitHub 仓库的 owner/repo 或完整 HTTPS 仓库地址，可指定技能名称，留空时安装仓库中发现的全部技能。界面不接受任意终端命令、私有仓库凭据或分支参数。

服务端使用固定版本的安装器：

```sh
npx --yes --package=skills@1.7.4 skills add owner/repo --agent codex --skill '*' --copy --yes
```

这是展示给用户的等效命令。实际执行会先读取 Git 文件清单，拒绝技能目录内的符号链接和子模块；技能目录外的元数据链接（例如仓库根目录的 CLAUDE.md）会被排除。仅将清单中的普通文件写入临时检出目录，npx 从这个经过验证的目录复制技能，防止安装器在复制时读取仓库之外的文件。仓库内容限 100 MiB / 5000 个文件；安装临时目录限 250 MiB / 20000 个条目；整个操作限 180 秒，并限制进程输出。源码、npm 缓存和安装输出均不保留在技能目录中。

Docker 的 web 镜像包含 Node.js、npm/npx 和 git。原生部署需要自行提供这些程序；技能页面会检查程序是否存在。安装仍需要服务器能访问 GitHub 和 npm registry，程序存在不代表网络连通或仓库可用。

安装器以服务账户执行，独立的临时目录和有限环境变量不等同于操作系统沙箱。仅安装自己了解来源的技能。安装器的遥测和 npm 生命周期脚本已关闭；模型密钥、数据库凭据、内部令牌不会传入安装子进程。

## 在项目中使用

1. 安装完成后，在当前项目中勾选技能。
2. 下一轮对话会固定所选技能的文件副本和 SHA-256；全局启用不会自动把技能应用于所有项目。
3. Codex 通过原生技能输入读取正文。需要附带文档或图片时，使用 read_skill_resource 工具按技能编号和相对路径读取。
4. 停用会移除所有项目对该技能的选择。卸载会移除技能中心中的版本。正在运行和历史任务使用的文件快照保留，不会被这些操作替换。

每个项目最多选择 20 个技能，一轮任务的技能正文合计不得超过 256 KiB。附带文本单次最多读取 128 KiB；PNG、JPEG 和 WebP 图片单次最多 5 MiB，读取后缩至不超过 1280 像素。图片解码也有像素上限。

同名技能不会自动覆盖。升级时先卸载再安装新版本，随后重新选择需要使用它的项目。每个任务的技能快照保存在项目任务目录中，与其他任务产物一起备份。

## 能力范围

技能可以指导建模、材质、灯光、质量检查和素材复用，也可以提供可由模型阅读的脚本源码及参考图片。Blender Pilot 的 Codex 运行时仍关闭通用 shell 和主机技能自动发现；需要运行宿主机命令、任意 npm 包或其他未配置工具的技能，安装成功后也不代表这些操作可执行。模型应明确说明缺少的能力，不能声称已经运行。

安装包元数据和项目选择存储在 PostgreSQL（迁移版本 4）；技能文件与任务快照保存在本地数据卷中。不要只备份数据库或只备份文件。

## 验证

tests/skills.test.ts 覆盖真实 API/数据库协议下的上传、重复安装回滚、项目隔离、停用、卸载、历史快照保留，以及压缩包边界、资源越界和文件改动校验。安装器进程测试与原生 Codex 协议测试分别覆盖 npx 子进程约束和实际技能注入。浏览器验收使用 npm run verify:skills；测试报告会区分本地模型协议模拟与真实模型推理。
